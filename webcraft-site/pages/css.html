③ 样式层：给页面穿上衣服

CSS 决定元素在哪里、多大、什么颜色。掌握盒模型与两套布局系统，绝大多数页面你都能自己写出来。

难度 ★★★☆☆预计 60 分钟原创插画
本页目录
盒模型 选择器与层叠 Flex 与 Grid 响应式 设计变量 样式清单

1. 先理解盒模型

页面里每个元素都是一个盒子，从内到外依次是：内容 content → 内边距 padding → 边框 border → 外边距 margin。CSS 布局的绝大多数"奇怪现象"，都来自没有正确理解这四层。

.card {
  width: 300px;        /* 内容宽度 */
  padding: 20px;      /* 内容与边框之间 */
  border: 1px solid #e2e8f0;
  margin: 16px;      /* 盒子与其他盒子之间 */
}

/* 全局设置：让 width 包含 padding 和 border，布局更可预测 */
* { box-sizing: border-box; }
必记：在项目第一行写上 * { box-sizing: border-box; }。这样声明宽度时得到的就是元素的实际宽度，不用手动做加法。

2. 选择器与层叠

CSS 通过选择器找到元素。常用的四类：

类型写法选择范围
元素p所有段落
类.card所有 class 含 card 的元素
ID#appid 为 app 的唯一元素
后代组合.card h3card 内部的 h3

多条规则命中同一元素时，按来源顺序 + 优先级决定胜负：后面的覆盖前面的，ID 优先于类，类优先于元素。实际开发中尽量用类选择器，少用 ID 和 !important。

3. 两套布局系统：Flex 与 Grid

Flexbox：一维排列

适合导航条、按钮组、卡片内部——元素沿一条轴线排布。

.nav {
  display: flex;
  justify-content: space-between; /* 主轴对齐 */
  align-items: center;             /* 交叉轴对齐 */
  gap: 16px;                      /* 元素间距 */
}

Grid：二维网格

适合页面整体框架、卡片矩阵——同时控制行和列。

.gallery {
  display: grid;
  grid-template-columns: repeat(3, 1fr); /* 三等分列 */
  gap: 20px;
}

/* 自适应列：空间够就排多列，不够自动换行 */
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(260px, 1fr));
}

经验法则：排一行或一列用 Flex，排网格用 Grid。两者可以嵌套使用。

4. 响应式：一套代码适配所有屏幕

响应式三件套：弹性布局、相对单位、媒体查询。核心思路是先写手机端样式，再在屏幕变宽时增强布局。

/* 默认：手机，单列 */
.cards { display: grid; gap: 16px; }

/* 平板及以上：两列 */
@media (min-width: 720px) {
  .cards { grid-template-columns: repeat(2, 1fr); }
}
/* 桌面：三列 */
@media (min-width: 1024px) {
  .cards { grid-template-columns: repeat(3, 1fr); }
}
  • 别忘了 HTML 里的 viewport meta 标签，否则媒体查询在手机上不生效；
  • 图片设置 max-width: 100%，避免溢出容器；
  • 字号用 rem、容器宽度用 % 或 fr，比写死像素更灵活。

5. 用变量管理设计系统

把颜色、圆角、间距等重复值抽成 CSS 变量，改一处即可全站生效——这也是本站点正在用的方式。

:root {
  --brand: #4f46e5;
  --ink: #0f172a;
  --radius: 16px;
}
.btn {
  background: var(--brand);
  border-radius: var(--radius);
}
调试技巧：浏览器按 F12 打开开发者工具，选中元素即可实时修改 CSS 并查看盒模型。先在这里试，再写回文件。
